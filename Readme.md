
# Leon Agency - Modern Minimalist Web Template

  

Leon is a creative, minimal, and fully responsive agency web template. It is designed for professional agencies that value simplicity and elegance. This template is the first project in a series of modern web designs.

>  **Note:** You can host your project on GitHub Pages or Netlify to add a live link here.

  

## ✨ Features

-  **Modern & Minimalist Design:** A clean look that focuses on content.

-  **Fully Responsive:** Optimized for all screen sizes (Mobile, Tablet, and Desktop) using CSS Media Queries.

-  **Interactive Elements:** Smooth hover effects on feature cards, portfolio items, and navigation links.

-  **Modern Layouts:** Built using **CSS Grid** and **Flexbox** for maximum flexibility.

-  **Smooth Scrolling:** Enhanced user experience with internal page navigation.

-  **Font Awesome Integration:** Beautifully curated icons for features and social media.

-  **Google Fonts:** Uses "Work Sans" for a professional and readable typography.

  

## 🛠️ Technologies Used

-  **HTML5:** For semantic web markup.

-  **CSS3:** For styling, animations, and custom properties (Variables).

-  **Normalize.css:** To ensure consistent rendering across different browsers.

-  **Font Awesome:** For scalable vector icons.

-  **Google Fonts:** For modern typography.
